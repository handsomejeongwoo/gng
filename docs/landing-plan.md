# 굿앤굿페이 랜딩페이지 구현 계획

## 목적

굿앤굿페이의 PG/결제대행 상담 전환을 위한 반응형 랜딩페이지를 만든다. 초기 버전은 기능을 크게 늘리지 않고, 가맹점 상담신청과 전화 상담 유도에 집중한다.

## Claude HTML 파악

- 구조는 헤더, 히어로, 신뢰 지표, 수수료, 입점 절차, 후기/파트너, FAQ, 상담 폼, 푸터로 구성되어 있어 프레임은 재사용 가능하다.
- 현재 톤은 종이 배경, 점선 테두리, 손글씨 폰트, 둥근 카드가 많아 친근하지만 PG 대행사의 공식성이나 자본력 표현에는 약하다.
- 한국어/영어/일본어 토글과 상담 CTA 흐름은 유지한다.
- 이미지 슬롯과 파트너 로고 영역은 실제 자료가 들어오기 전까지 신뢰형 플레이스홀더로 처리한다.

## 디자인 방향

- 톤: 따뜻한 스케치 느낌이 아니라, 담백하고 신뢰감 있는 B2B 금융/결제 서비스 톤.
- 컬러: 흰색/옅은 회색 기반, 진한 네이비 계열 텍스트, 차분한 블루 포인트.
- 폰트: 둥근 손글씨 계열 제거. 시스템 산세리프 기반으로 또렷하게 구성한다.
- 형태: 큰 라운드와 장식성 테두리를 줄이고, 얇은 보더와 명확한 그리드로 정리한다.
- UX: 첫 화면에서 핵심 카피, 월 처리 규모, 정식 등록 신뢰 문구, 상담 CTA가 바로 보여야 한다.

## 페이지 섹션

1. 헤더
   - 로고
   - 수수료, 입점 절차, 후기, FAQ, 상담신청 이동
   - 한국어/영어/일본어 토글
   - 전화 상담 CTA

2. 히어로
   - 메인 카피
   - 월 처리 규모 1,000억, 정식 등록 업체 신뢰 배지
   - 상담신청, 전화상담 CTA

3. 신뢰 지표
   - 월 처리 규모
   - 정식 등록
   - 온라인/오프라인 가맹점 대응
   - 상담 중심 온보딩

4. 수수료/요금 안내
   - 업종/결제 방식별 협의 구조
   - 상담 후 조건 안내

5. 입점 절차
   - 상담 접수
   - 업종/매출 확인
   - 조건 안내
   - 계약 및 연동

6. 후기/파트너
   - 초기에는 실명 로고 대신 업종 기반 후기 카드와 파트너 슬롯

7. FAQ
   - 초기 상담 전 자주 묻는 질문 중심

8. 상담신청 폼 + 고객센터
   - 회사명, 담당자명, 연락처, 업종, 월 예상 매출, 문의 내용
   - 개인정보 동의 체크
   - 전화 상담 유도

## 구현 기준

- Next.js App Router 단일 랜딩 페이지로 먼저 구현한다.
- 다국어는 서버 라우팅이 아니라 클라이언트 토글 상태로 시작한다.
- 상담 폼은 초기에는 제출 UI만 만들고 실제 전송 연동은 추후 추가한다.
- 모바일에서는 헤더 메뉴를 압축하고 CTA와 상담 폼 접근성을 우선한다.
- 개발 첫 단계에서는 외부 이미지 없이 CSS 기반 신뢰형 레이아웃으로 구현한다.
